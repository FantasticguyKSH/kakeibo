2. 앱이 처리하는 데이터

앱은 가계부 기능 제공을 위해 사용자가 직접 입력하거나 설정한 다음 정보를 기기 안에서 처리합니다.

  • 거래 날짜, 수입·지출·이체 구분, 금액
  • 카테고리, 자산, 메모
  • 사용자가 추가하거나 수정한 수입·지출 카테고리 및 자산 목록
  • 사용자가 내보내거나 가져오는 백업 파일

앱은 회원가입이나 사용자 계정을 제공하지 않습니다.

3. 처리 목적

  • 거래 기록의 저장, 조회, 수정 및 삭제
  • 월별 수입·지출 합계와 카테고리별 통계 표시
  • 자산별 잔액 계산
  • 사용자가 요청한 데이터 백업 및 복원

4. 수집, 전송 및 공유

개발자는 사용자가 입력한 거래·카테고리·자산 데이터를 수집하거나 개발자 운영 서버로 전송하지 않습니다. 앱에는 광고 SDK, 이용 분석 SDK 또는 사용자 추적 SDK가 포함되어 있지 않습니다.

사용자가 “백업 파일 내보내기”를 실행하면 앱은 기기에 JSON 형식의 백업 파일을 만들고 Android 공유 화면을 엽니다. 파일은 사용자가 직접 선택한 파일 저장소, 클라우드, 이메일 또는 다른 공유 앱으로 전달될 수 있습니다. 이때 선택한 외부 서비스의 데이터 처리는 해당 서비스의 개인정보처리방침을 따릅니다.

개발자는 사용자가 외부 서비스로 보낸 백업 파일에 접근할 수 없습니다.

5. 저장 위치와 보안

가계부 데이터는 앱의 기기 내부 저장 영역에 저장됩니다. 백업 파일은 사용자가 내보내기를 실행했을 때 임시 캐시 영역에 생성되고, 시스템 공유 기능을 통해 사용자가 선택한 위치로 전달됩니다.

기기의 잠금, 운영체제 보안 업데이트, 백업 파일의 보관 위치와 접근 권한을 안전하게 관리해 주세요. 메모나 카테고리에 계좌번호, 카드번호, 비밀번호 등 민감한 정보를 입력하지 않는 것을 권장합니다.

6. 보유 기간과 삭제 방법

기기 안의 데이터는 다음 중 하나가 발생할 때까지 유지될 수 있습니다.

  • 사용자가 앱에서 개별 거래·카테고리·자산을 삭제하는 경우
  • 사용자가 백업 파일을 가져와 기존 데이터를 교체하는 경우
  • Android 설정에서 앱 저장공간을 삭제하는 경우
  • 앱을 삭제하는 경우

별도로 내보낸 백업 파일은 사용자가 저장한 파일 앱이나 클라우드에서 직접 삭제해야 합니다. 개발자는 기기 내부 데이터와 사용자가 보관한 백업 파일을 원격으로 조회하거나 삭제할 수 없습니다.

7. 기기 권한과 외부 서비스

앱은 핵심 가계부 기능을 위해 연락처, 위치, 카메라 또는 마이크 정보에 접근하지 않습니다. 파일 선택 및 공유 기능은 사용자가 백업·복원 버튼을 누른 경우에만 운영체제의 파일 선택기와 공유 기능을 사용합니다.

Google Play, Android 운영체제, 기기 제조사 또는 사용자가 선택한 공유·저장 서비스는 각자의 서비스 운영 과정에서 별도의 정보를 처리할 수 있으며, 해당 처리는 각 사업자의 방침을 따릅니다.

8. 아동의 개인정보

앱은 사용자의 개인정보를 개발자에게 전송하거나 회원 계정을 생성하지 않습니다. 아동을 포함한 모든 사용자는 백업 파일에 금융 관련 기록이 포함될 수 있다는 점을 이해하고 안전한 위치에 보관해야 합니다.

9. 개인정보의 국외 이전

개발자는 앱 데이터를 수집하거나 국외로 이전하지 않습니다. 다만 사용자가 해외 사업자가 운영하는 클라우드·이메일·공유 서비스를 직접 선택한 경우에는 해당 서비스의 정책과 저장 위치가 적용될 수 있습니다.
